# AI Recommendation Interface

**Description**
Design a "Smart Match" interface where a user can enter a complex sentence (e.g. "I am a Data Engineer who knows Python and Azure") and instantly get the top 5 AI-matched job roles using the `GET /recommend/` endpoint.

**Acceptance Criteria:**
- [ ] A dedicated page/route for AI Recommendations.
- [ ] A large, prominent text input for user profiles/queries.
- [ ] Visual indication (loading spinner) while the NLP engine scores the jobs.
- [ ] Result view highlighting the matched jobs and their dynamic "Match Score".
- [ ] A badge showing the exact Skills the AI detected from the user's sentence.
