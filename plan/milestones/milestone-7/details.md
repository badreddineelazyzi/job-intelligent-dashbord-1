# Milestone 7: Frontend Web Application

## Overview
Build a modern, interactive web application (similar to Indeed or LinkedIn) to serve as the user interface for the Job Intelligence platform. This application will consume the FastAPI backend endpoints created in Milestone 6 to display job listings and AI-powered recommendations.

## Goals
1. Establish a modern Frontend architecture using React (Vite).
2. Build a Job Board interface with search and pagination capabilities.
3. Build an AI Recommendation page where users can input their profile/skills and get matched jobs.

## Tasks
* **Issue 1:** Frontend Foundation Setup (Project scaffold, Tailwind CSS/Styling, Routing).
* **Issue 2:** Job Search & Discovery UI (Listing, Pagination, Filtering, Job Details).
* **Issue 3:** AI Recommendation UI (Search bar for NLP query, displaying Top matched jobs).
