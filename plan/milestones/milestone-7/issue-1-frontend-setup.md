# Frontend Foundation Setup

**Description**
Initialize the base frontend platform (using React (Vite)) and configure the styling engine (Tailwind CSS/Bootstrap). Set up HTTP client (Axios/Fetch) to talk to the local FastAPI backend.

**Acceptance Criteria:**
- [ ] The base frontend web app starts on localhost.
- [ ] Essential UI layout (Navbar, Footer, Main Container) is present.
- [ ] Connects successfully to the `http://127.0.0.1:8000/` API without CORS errors.
