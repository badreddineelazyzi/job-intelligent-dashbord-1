# Job Search & Discovery UI

**Description**
Build the main "Jobs Board" view similar to Indeed, presenting paginated results from the PostgreSQL database using the `GET /jobs/` endpoint.

**Acceptance Criteria:**
- [ ] List of jobs displayed in grid/list format (Title, Salary, Company, Location, Experience Level).
- [ ] A search bar to filter by basic keywords.
- [ ] Pagination buttons (Next/Previous).
- [ ] Clicking a job card shows detailed job descriptions.
